# Skyfare_AI
 # ✈ Flight Fare Prediction Using Machine Learning

This project predicts flight ticket prices using Machine Learning techniques. The model analyzes various factors such as airline, source, destination, journey date, duration, arrival time, departure time, and total stops to estimate the expected fare.

## Features

* Complete Exploratory Data Analysis (EDA)
* Data Cleaning and Feature Engineering
* Multiple Model Training and Comparison
* Linear Regression, Decision Tree, and Random Forest Models
* Best Model Selection Based on Performance Metrics
* Model Serialization using Pickle
* Ready for Flask Web Application Deployment

## Model Performance

| Model             | R² Score |
| ----------------- | -------: |
| Linear Regression |   0.7526 |
| Decision Tree     |   0.8562 |
| Random Forest     |   0.8800 |

## Technologies Used

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Scikit-Learn
* Flask
* Pickle

## Outcome

Random Forest Regressor achieved the highest accuracy and was selected as the final model for deployment.
